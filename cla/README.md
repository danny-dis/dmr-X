# Contributor License Agreements

This directory contains signed Contributor License Agreements (CLAs) from contributors to the DMR-X project.

## About CLAs

All contributors must sign a CLA before their contributions can be merged. The CLA grants the project maintainers the right to relicense the project as needed, including under commercial licenses.

## How to Sign

1. See [CLA.md](../CLA.md) for the full agreement
2. Fill in the required fields
3. Sign and date
4. Submit a scanned copy or photo to: [Your Email Here]
5. Or create a pull request adding your signed CLA to this directory

## File Naming

Please name your signed CLA file as follows:
- Individual: `individual-<github-username>.md`
- Corporate: `corporate-<company-name>.md`

## Verification

Pull requests will not be merged until the contributor's CLA is on file in this directory.
