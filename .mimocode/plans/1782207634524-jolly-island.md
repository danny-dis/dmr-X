# Plan: Deploy DMR-X Locally

## Steps

1. **Install dependencies** — `bun install` (if not already done)
2. **Start all services** — `bun run dev` (turbo runs gateway + UI dev tasks in parallel)
   - Gateway: `http://localhost:3000`
   - UI: `http://localhost:4200` (Vite dev server, proxies `/v1/*` to gateway)
3. **Verify** — `curl http://localhost:3000/health` should return `{"status":"ok"}`

## Notes

- `.env` is already configured with `DMRX_LOCAL_MODE=true` and `NODE_ENV=development` — no auth required for local dev
- No provider API keys are set, so routing will have no candidates until one is configured via the admin UI or env vars
